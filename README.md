# 🍽️ Mi Llanerita - Restaurante Web

**Sitio web moderno y responsivo para restaurante llanero con React, Vite y Framer Motion.**

![Mi Llanerita](https://img.shields.io/badge/React-18-61DAFB?style=for-the-badge&logo=react&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-646CFF?style=for-the-badge&logo=vite&logoColor=white)
![Framer Motion](https://img.shields.io/badge/Framer_Motion-0055FF?style=for-the-badge&logo=framer&logoColor=white)

## ✨ Características

- 🎨 **Diseño moderno** con animaciones profesionales
- 📱 **Totalmente responsivo** para todos los dispositivos
- 🍴 **Carta interactiva** con búsqueda y filtros
- 📅 **Sistema de reservas** integrado con WhatsApp
- 🎉 **Gestión de eventos** especiales
- 🖼️ **Galería de fotos** con lightbox
- ✨ **Efectos glassmorphism** y parallax
- ⚡ **Rendimiento optimizado** con Vite

## 🛠️ Tecnologías

- **Frontend:** React 18, Vite, Framer Motion
- **Estilos:** CSS3, Variables CSS, Grid/Flexbox
- **Navegación:** React Router
- **Estado:** Context API
- **Integración:** WhatsApp API

## 🚀 Instalación y Uso

### Prerrequisitos
- Node.js (versión 16 o superior)
- npm o yarn

### Instalación
```bash
# Clonar el repositorio
git clone https://github.com/Stivenz3/Restaurante.git

# Navegar al directorio
cd Restaurante

# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev
```

### Scripts disponibles
```bash
npm run dev      # Servidor de desarrollo
npm run build    # Construcción para producción
npm run preview  # Vista previa de la construcción
npm run lint     # Linter de código
```
